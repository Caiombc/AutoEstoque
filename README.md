# AutoEstoque

Trabalho da disciplina de Engenharia de Software (UFOP).

O projeto demonstra boas práticas de desenvolvimento: versionamento com
Git e Gitflow, organização de repositório, automação de build com Makefile
e Desenvolvimento Dirigido por Testes (TDD).

## Como compilar

    make          # compila a aplicação em bin/app.exe
    make test     # compila e executa os testes
    make clean    # remove os binários
